# 被子植物解剖圖集 · Angiosperm Tree Anatomy Atlas

教科書風格嘅被子植物（木本雙子葉）解剖圖集，由器官剖開去到細胞層。圖上可以撳結構睇中文說明。

呢個唔係低面數遊戲模型。畫面係教學用 3D 插畫／染色切片重建，細胞排列跟 Esau、Evert、Raven、Taiz 同 IAWA 通例。

## 本機打開

雙擊 `index.html` 通常已經得。如果瀏覽器擋住本地圖片，用：

```bash
cd angiosperm-tree-anatomy-atlas
python3 -m http.server 8765
```

然後開 <http://localhost:8765>。

GitHub Pages：Settings → Pages → Deploy from branch → `/`（root）。

## 圖版

| 圖 | 尺度 | 教咩 |
|---|---|---|
| 葉肉立體切片 | 200–400 µm | 表皮、柵欄、海綿、葉脈極性、氣孔 |
| 葉脈細胞 | 10–80 µm | 篩管／篩板／伴胞、導管／穿孔／紋孔、管胞、纖維 |
| 運輸 | 器官 | 木質部向上、韌皮部由源到庫 |
| 氣孔 | 20–50 µm | 腎形保衛細胞 |
| 初生莖橫切 | mm | 管束成環、外韌內木、內始式 |
| 木本莖染色橫切 | mm–cm | 髓、年輪、形成層、韌皮部、木栓 |
| 樹幹立體剖開 | cm | 樹皮、邊材、心材、射線 |
| 維管形成層 | 幾十 µm | 紡錘／射線原始細胞；向內木質部、向外韌皮部 |
| 木質部縱切 | µm | 導管、管胞、纖維、活射線 |
| 幼根橫切 | mm | 根毛、皮層、凱氏帶、外始式木質部星 |
| 根尖縱切 | mm | 根冠、分生區、伸長區、成熟區 |
| 莖端分生組織 | 百 µm | tunica–corpus、葉原基、原形成層 |
| 花剖開 | mm | 花萼花冠、花藥花粉、子房胚珠 |

## 科學邊界

- 教學重建，唔係某一樹種、某一張真切片相。
- 細胞數量、年輪闊度、導管直徑只係示意。
- 根木質部原型數真實種有三至六；教學常畫四原型。
- 呢版只覆蓋普通雙子葉木本樹，唔包括單子葉、異常形成層。

詳細出處見 [`SOURCES.md`](SOURCES.md)。
